Automatic backups and recovery

Save a daily or weekly schedule in Backups. Times are UTC; weekly backups run
on Monday. Risulta checks the saved schedule every minute using its own binary.
No Python, cron entry or separate maintenance service is required.

A separate process of the same executable creates consistent SQLite snapshots
without blocking the web process. Scheduled retention only deletes recorded
automatic snapshots. Manual snapshots are kept. A missed daily backup runs
on the next check later that same UTC day.

Keep private copies off the server. Snapshots include account and session data.

To restore: stop Risulta, preserve the current database and WAL sidecars, and
restore a verified snapshot at d1/DB.sqlite. Preserve ownership and restart.
Test restoration on a separate instance first. Restore the matching executable
when changing between incompatible schema versions.
