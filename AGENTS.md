# Repository instructions

- Do not use em dashes in user-facing copy, comments, documentation, or source strings. Use commas, parentheses, colons, or hyphens instead.

- Stable releases must provide supported production features from the Risulta binary. Do not publish v0.1.7 until rollup processing and scheduled backups work without external Python workers. Features that cannot run from the binary must remain unsupported for that stable release.
